# Sumit 3D Portfolio

Open `index.html` in a browser.

Included:
- Responsive one-page portfolio
- Animated 3D-inspired hero with mouse interaction
- Projects, education, skills, internship, certifications and achievements
- Clickable email/phone
- Contact form that opens the visitor's email client
- Resume download
- Mobile navigation

Before deployment, replace the placeholder GitHub/Live Demo links with your real URLs.
For true server-side contact form submission, connect the form to Formspree, EmailJS, Resend, or another email service.
